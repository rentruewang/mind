# What processes are similar

A task can be broken down into steps.

If 2 tasks have similar steps, they are similar.

As long as there are no additional work being done, it's fine.

When you refactor some code, and merge similar processes together, you identify common checkpoints and then make the pipeline the same. If the original if-else / arbitrary program is too complicated and have nothing in common, then this cannot be done.

Not similar: conceptually different = use in different places. When can a function be used? Pre and post conditions are satisfied.
